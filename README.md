# Projecte: EverPia 3 — “Sobreviure en una empresa IT”

## Descripció
Després de setmanes convivint amb el ritme imprevisible d’una consultora tecnològica, arriba el darrer capítol de la trilogia EverPia. Un moment que combina entusiasme, maduresa i una sensació molt real: aquesta etapa s’acaba i comença una de nova.

A EverPia, ningú entra sabent què s’hi trobarà. Però tothom en surt transformat: apagant incendis digitals, resolent problemes d’origen desconegut i aprenent a velocitat de fòrmula 1 sense manual d’instruccions. Aquesta pressió et converteix en professional.

Aquest projecte representa exactament aquest punt: quan ja no ets el júnior espantat del primer dia. Ara tens eines, criteri i una mirada tècnica madura.

## Missió del projecte
Demostrar que l’alumne és capaç de:
- Resoldre encàrrecs reals dins una infraestructura IT.
- Implementar serveis corporatius essencials.
- Automatitzar, documentar i millorar processos tècnics.
- Gestionar flux de treball amb metodologia professional.
- Mantenir la calma mentre els servidors decideixen no col·laborar. 😅

## Objectius formatius
- Integrar coneixements de Seguretat, Sistemes i Web en un context professional.
- Dominar estratègies de backup i recuperació (DRP).
- Deploy de serveis corporatius (SSH, NFS, CUPS…).
- Consolidar habilitats en prototipat i disseny digital (Figma).
- Fer servir Git com a base de control de versions.
- Documentar tècnicament amb qualitat professional.
- Aplicar criteris de sostenibilitat i economia circular.
- Desenvolupar competències d’organització, equip i autonomia real.
